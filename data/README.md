# Private runtime data

This directory holds local SQLite databases, generated handovers, and other customer-sensitive artifacts.

Do not commit:

- CRM databases
- Customer contact details
- Credentials, tokens, OAuth artifacts
- Customer-specific handovers
- Exported customer lists

Research-only files explicitly committed at the repository root, such as the Companies House-derived prospect CSV, do not contain verified phone numbers, marketing permission, or TPS/CTPS results.
