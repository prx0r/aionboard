# FREE_ONBOARD.md

> Free onboarding for the first 20 businesses. Validation phase, not marketing.

## Why

We have 11 verticals built from research. We need to prove them with real businesses:
1. Prove workflows actually work
2. Find what goes wrong → add to rulebooks
3. Measure before/after for case studies
4. Learn which verticals are easiest to deliver
5. Build referral engine from real customers

**PLAYBOOK.md rule:** "Do it manually for 5 customers. Read every output. Write down every mistake." We're doing 20 for vertical coverage.

---

## Application process

### Step 1: Apply (2 minutes)

```
1. Business name + postcode
2. Phone + email
3. Vertical (dropdown)
4. Biggest challenge right now (text)
5. Current booking method (dropdown)
6. Enquiries per week (0-5 / 5-15 / 15-30 / 30+)
7. UK-based? (yes/no)
8. Can commit to 4 weeks? (yes/no)
```

### Step 2: Qualify (5 minutes)

Check: vertical covered? Existing enquiries? UK-based? Can commit?
- Yes → accept immediately
- No → waitlist

### Step 3: Onboarding call (15 min)

**We do:**
1. Learn current workflow
2. Get booking tool access
3. Get price list
4. Set up AI receptionist
5. Add booking link to socials
6. Configure reminders
7. Set up review requests

**They do:**
1. Show current setup
2. Confirm services and prices
3. Test AI with fake enquiry

### Step 4: Go live (day 1)

- AI answers enquiries
- Booking link live in bios
- Reminders firing
- We monitor everything

### Step 5: Week 2 check-in (15 min)

**We:** Review metrics, ask what's working/not, fix issues, update rulebooks
**They:** Give honest feedback, show issues, tell us what they'd tell a friend

### Step 6: Week 4 review (15 min)

**We:** Present before/after metrics, offer paid options, ask for review + referral
**They:** Review data, decide on paid, give review, refer one friend
