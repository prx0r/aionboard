# Dog Groomers pack

Proposed surface: `groomers.aionboard.co.uk`. Parent vertical: petcare.

Narrow pilot for dog groomers: recurring appointments, reminders, client and pet records, waiting lists, reviews, and discovery readiness.

Prices of £349–£499 are hypotheses from `../../targets.md`, not measured willingness to pay. Canonical pilot scope remains in `../../OFFER.md`.

Dog grooming is adapted from the broader petcare research pack; there is no dedicated cgraphuk dog-grooming template yet.
