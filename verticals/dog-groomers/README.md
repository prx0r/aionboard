# Dog Groomers pack

Proposed surface: `groomers.aionboard.co.uk`. Parent vertical: petcare.

Narrow pilot for dog groomers: recurring appointments, reminders, client and pet records, waiting lists, reviews, and discovery readiness.

Prices of £20 + add-ons are hypotheses from `../../targets.md`, not measured willingness to pay. Canonical pilot scope remains in `../../OFFER.md`.

Dog grooming is adapted from the broader petcare research pack; there is no dedicated cgraphuk dog-grooming template yet.

## Files

| File | Purpose |
|------|---------|
| `profile.json` | Machine-readable vertical profile: pains, stack, legal, finance, tax |
| `RULEBOOK.md` | Failure modes and fixes — the moat |
| `INTAKE.md` | 5-field intake form adapted to pet grooming salons and mobile groomers |
| `OUTCOMES.md` | Offer rewritten as outcomes with measurement framework |
