# Mobile Hairdressers and Braiders pack

Proposed surface: `hair.aionboard.co.uk`. Parent vertical: beauty.

Narrow pilot for mobile hairdressers and braiders: portable booking workflow, service-area information, social enquiry handling, portfolio organization, reminders, rebooking, reviews, and discovery readiness.

Prices of £299–£499 are hypotheses from `../../targets.md`, not measured willingness to pay. Canonical pilot scope remains in `../../OFFER.md`.
