# Domestic cleaner installation checklist

Manual-first pilot checklist. Every task needs an owner, authorization, action, verification, evidence, and status.

- `discovery`
- `email_authorization`
- `calendar_authorization`
- `recurring_scheduling_workflow`
- `service_menu_approval`
- `quote_follow_up_preparation`
- `owner_message_approval`
- `payment_reminder_preparation`
- `customer_management_organization`
- `google_profile_assistance`
- `training`
- `handover`
- `fourteen_day_fixes`

Task status:

- `not_started`
- `in_progress`
- `blocked`
- `verified`

A task is complete only after verification evidence exists. Failed or pending third-party verification cannot be marked complete.

Separate optional tasks:

- `website_build`
- `live_voice_service`
- `meta_production_integration`
- `custom_integration`
- `lead_generation`

Trust rules for every task: customer-owned accounts, no passwords held, owner approval before sends, revocation documented. See `../../TRUST_MODEL.md`.
