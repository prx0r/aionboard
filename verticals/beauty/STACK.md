# Beauty stack

Use the customer’s existing software where possible. Import data rather than replacing systems unnecessarily.

## Booking and marketplace: integrate where access allows

- Booksy
- Fresha
- Square Appointments

## Salon management: import from

- Phorest
- Vagaro
- GlossGenius
- Mangomint
- Mindbody
- Pabau for clinical/medspa-adjacent work

## Client and package data: import from

- Fresha or Phorest exports
- Vagaro exports
- Existing spreadsheets or booking exports, where the customer authorizes use

## Communications

- Keep the customer’s existing phone number unless they explicitly request a change.
- Live voice and WhatsApp production integration are separate deliverables.
- Outbound booking, payment, deposit, and review messages require explicit approval.

## Safety and privacy

- Patch-test and allergy records must be retained and checked before relevant treatments.
- Client photos and preferences are personal data.
- Never publish identifiable client images without explicit written consent.
